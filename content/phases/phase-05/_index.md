## Что такое «Прометей-РФ»

Лабораторный электромагнитный разгонник массой 30-50 м, выводящий капсулы массой 10-50 кг на скорость 200-500 м/с. Российский эквивалент Auriga Prometheus (США), который превращает Урал-Драйвер из концепт-документа в технологически активную программу.

### Параметры

| Параметр | Значение |
|---|---|
| Длина | 30-50 м |
| Конечная скорость | 200-500 м/с |
| Масса разгоняемого тела | 10-50 кг |
| Энергия пуска | 0,5-3 МДж |
| Импульсная мощность | 10-30 МВт |
| Цикл пусков | 1 в час, 100+ за период |
| Бюджет | **₽300-450 млн** |
| Срок | 2027-2030 (3 года) |

### Зачем именно лаборатория, а не сразу демонстратор

Демонстратор Фазы 1 ($2,5 млрд) — это слишком большой шаг от концепта Фазы 0 ($0,12 млрд). Между ними **valley of death**: ни один государственный заказчик не выдаст $2,5 млрд без подтверждения физики на железе. Прометей-РФ закрывает этот разрыв.

### Что доказывает

1. **Физика маглев-подвеса** на сверхпроводящих магнитах с криогенным охлаждением.
2. **Линейный синхронный двигатель (LSM)** в импульсном режиме — переход энергии в кинетическую с КПД 75%+.
3. **Импульсная энергетика** — масштабируемые накопители-преобразователи (NIIEFA, ВНИИЭФ).
4. **Управление траекторией** капсулы в реальном времени с обратной связью.

После успеха Прометея-РФ масштабирование к 1,5 км демонстратору становится **инженерной задачей**, а не научным риском.

## Стратегия финансирования (mix-канал)

| Канал | Сумма | Доля |
|---|---|---|
| МО НИОКР (через 12-ЦНИИ или НПО Машиностроения) | ₽100-150 млн | 33% |
| РНФ + Минобрнауки (грант на маглев-инфраструктуру) | ₽50-80 млн | 18% |
| In-kind НИИЭФА + Курчатовский (магниты, криогеника) | ₽100-150 млн (эквивалент) | 33% |
| Сколково (резидентство + грант) | ₽30-50 млн | 11% |
| Краудфандинг через АНО (Planeta.ru / Boomstarter) | ₽20-30 млн | 5% |
| **ИТОГО** | **₽300-460 млн** | 100% |

Mix-стратегия — главный механизм запуска: ни один из каналов сам по себе не закрывает проект, но в совокупности они даже устойчивы к выпадению одного из них.

## Каскадный эффект

После успешного запуска Прометея-РФ открываются:

### 1. Государственный канал
- Минобороны видит работающий прототип → готов финансировать рейлган-программу;
- Росатом видит партнёра, способного работать с импульсной электротехникой → in-kind магниты для Фазы 1;
- Минобрнауки получает phd-defenses и публикации Q1 → готов открыть отдельную программу.

### 2. Международный канал
- Через US co-PI (Auriga Space partnership): NIAC grant Phase I-II;
- Через ESA: совместный workshop по non-rocket access;
- Через Китай: ILRS observer + Опция B (лунный масс-драйвер).

### 3. Команда
- 50-80 инженеров, способных работать на Фазе 1;
- 5-10 phd-кандидатов, защитивших диссертации на Прометее;
- Сложившаяся группа NIIEFA + ВНИИЭФ + Курчатовский, привыкшая к совместной работе.

### 4. Медиа и signal-эффект
- Документальный фильм про Прометей (₽5-15 млн, окупится через продакт-плейсмент);
- Книга-эссе по концепту в Bombora/АСТ (₽1-3 млн аванс);
- Серия публикаций на Хабре, в "Кванте", в "Природе" — формирует общественный спрос.

## Главные риски

### Риск 1: Финансовый (вероятность 40%)
**Если выпадает МО НИОКР или РНФ, проект тормозит.**

*Митигация:* избыточная mix-структура — 5 каналов покрывают одно и то же; крауд-кампания как буфер; in-kind институтов как несгораемый запас.

### Риск 2: Технический (вероятность 25%)
**Если LSM в импульсном режиме не достигает заявленного КПД.**

*Митигация:* демонстрация на капле параметров (Prometheus 30 м, V=200 м/с) — это уровень рейлгана ОИВТ РАН, физически точно достижимо. Запас по бюджету ₽50 млн на эксперименты.

### Риск 3: Регуляторный (вероятность 15%)
**Если ФСБ блокирует международные partnerships из-за рейлган-импликаций.**

*Митигация:* юр.wrapper Vedi-Workspace EU + параллельная российская АНО; международные публикации только по civilian-aspects; военные данные только через закрытый госконтракт.

### Риск 4: Кадровый (вероятность 10%)
**Утечка ключевых специалистов в Auriga, SpinLaunch, Type 076.**

*Митигация:* конкурентная зарплата + долгосрочная программа развития; PhD-defenses как retention; проект как национальная гордость.

## Timeline до перехода к Фазе 1

```
2026 Q3-Q4: Юр.wrapper + первичные переговоры (₽5 млн)
2027 Q1-Q2: Контракт МО НИОКР подписан (₽30-50 млн получены)
2027 Q3-Q4: РНФ грант + Сколково резидентство (₽50-100 млн)
2028 Q1-Q2: Стройка лабораторного корпуса 50 м в Сарове или Дубне
2028 Q3-Q4: Поставка магнитов (НИИЭФА), криогеники (Курчатовский)
2029 Q1-Q2: Сборка LSM + первые холодные испытания
2029 Q3-Q4: Первый разгон до 100 м/с — медийное событие
2030 Q1-Q2: Полная программа испытаний (V=200-500 м/с, 100+ пусков)
2030 Q3-Q4: Финальный отчёт, публикации, gate-review к Фазе 1
2031+: Старт Фазы 1 (с 5-летним опережением исходного плана)
```

**Ключевая метрика успеха:** к концу 2030 года иметь работающий Прометей с задокументированной программой испытаний, готовый для масштабирования до 1,5 км демонстратора.

## Auriga Space как технический бенчмарк

Winnie Lai (ex-VP SpinLaunch) построила Prometheus 30 м в США в 2025-2026 на $5M Seed. Это **прямой ориентир** для российского Прометея-РФ:

| Параметр | Auriga Prometheus | Прометей-РФ |
|---|---|---|
| Длина | 30 м | 30-50 м |
| Скорость | 200-300 м/с | 200-500 м/с |
| Бюджет | $5M (~₽450 млн) | ₽300-450 млн |
| Срок | 2 года | 3 года |
| Финансирование | Private VC | Mix (МО + РНФ + in-kind) |
| Architecture | Электромагнитная катапульта | Маглев + LSM |

Прометей-РФ должен **идти параллельно** Auriga, не догонять. Российский путь через mix-канал даёт устойчивость к VC-зимам и санкционным эффектам.
