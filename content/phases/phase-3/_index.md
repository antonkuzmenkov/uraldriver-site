## Что делается

Фаза 3 — **программа испытаний**: 200+ пусков с постепенным выходом на проектные параметры v3.2 (2,5 км/с в тоннеле + бортовая маршевая ступень РДТТ + малая твёрдотопливная ракета до орбитальных 7,8 км/с), отладка всех систем, накопление статистики надёжности.

### Главные работы

| Блок | Стоимость |
|---|---|
| Серийные капсулы (200+ единиц) | $2 млрд |
| Полезные нагрузки (топливо, расходники, тестовые грузы) | $1,5 млрд |
| Эксплуатационные расходы | $1,5 млрд |
| Доработка систем по результатам испытаний | $1 млрд |
| Резерв на нештатные ситуации | $1 млрд |
| **ИТОГО** | **$7 млрд** |

### Критерии завершения

- 95% надёжность пусков;
- Полная цепочка «маглев 2,5 км/с → гелиевый буфер → майларовая мембрана → быстрый клапан → маршевый РДТТ 2,5 км/с → твердотопливная 0,3 км/с → орбитальные 7,8 км/с» отработана и сертифицирована;
- Контракты на регулярную эксплуатацию (Фаза 4) от российского + международного заказчика;
- Окупаемость по экономике пусков (удельная стоимость $/кг подтверждена в реальных пусках).

### Главные риски

- **Спрос:** к 2040 году цислунарная экономика может задержаться (Артемис задерживается, ILRS буксует) — рынок может оказаться меньше прогноза;
- **маршевая ступень РДТТ в гражданском режиме:** перенос «Тополя»/«Искандера» от КТРВ на гражданские пуски — отработанная технология серии с 1985 года;
- **Регуляторика:** выход на международный рынок при сохранении санкций.
